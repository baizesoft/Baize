# 白泽（Baize）

白泽是一门以中文为主要书写语言、以编译器自举为目标的开源编程语言。源文件统一使用 `.bz` 后缀。

**当前状态：** 项目已初始化，编译器尚未实现。以下示例仅用于讨论语法，目前不可运行。

```text
输出（“你好，白泽！”）
```

示例文件：[你好.bz](examples/你好.bz)。

## 第一个里程碑：自举

1. 用 Rust 实现一个种子编译器，支持编写编译器所需的最小白泽子集，并生成 C 代码。
2. 用白泽重写这套编译器，由种子编译器生成第一代白泽编译器。
3. 移走 Rust 种子，让白泽编译器编译自身源码。用连续两代编译器运行同一套测试，核对生成的 C 代码。

首个里程碑允许依赖 C 工具链；不依赖 C 工具链可作为后续目标。
