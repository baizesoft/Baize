# 白泽官方测试命令（基础版）

```text
python3 -B scripts/baize.py test --compiler <本机白泽编译器> --合入 examples/源码行统计核心.bz examples/源码行统计测试
python3 -B scripts/baize.py test --compiler <本机白泽编译器> --合入 examples/源码行统计核心.bz --filter 行尾 --json examples/源码行统计测试
```

- 递归发现 `*.test.bz` 文件，按相对路径排序；`--filter` 按相对路径字面匹配，不执行正则。普通 `.bz` 不视为测试；可用 `--合入` 为每个测试加入纯业务源码，允许重复传入。当前不跟随符号链接，也不自动引入同目录源码。
- 测试是普通白泽源码。`测试断言整数(实际, 期望, 用例行)`、`测试断言真(布尔值, 用例行)` 来自随工具链提供的 `标准库/测试.bz`。行号由用例传入，按原始测试文件从 1 计数，不是自动源码定位。断言失败会累积，最后由运行器追加的结算让进程退出非零。
- 退出码：`0` 全部通过且每个用例实际断言；`1` 至少一个用例失败；`2` 没发现匹配用例或工具参数／环境错误。报告区分断言失败、编译失败、提前退出、零断言、超时和输出超限。`--json` 为结构化报告，含 `schema_version`、总计、路径、状态、断言数、失败行和实际／期望值。
- 当前只跨 Windows / Linux x86-64 本机编译与运行。每个用例在独立临时工作目录运行，标准输入关闭，编译和运行各受 `--timeout` 约束（默认 10 秒），单进程每个输出流最多采集 1 MiB。这些是隔离产物和限制资源的措施，不是沙箱；只运行受信任的白泽测试。用例不要输出保留的测试协议标记。
- 宿主运行器用 Python 标准库；断言、合入的业务程序和生成的测试可执行文件由白泽编译运行。无需在产物侧安装 Python。该命令是白泽程序的测试入口，与编译器自己的内部回归脚本分开。

验收：`python3 -B tests/check-official-test-command.py <第三代编译器>`。真实行数工具共用同一份行数函数；测试在副本中把一次换行累加改成加两次，官方命令必须报告两个实际失败位置，原始核心不修改。
