# 动态字节向量与首版垃圾回收

`字节向量` 是独立静态引用类型，可作形参、返回值和函数局部变量。向量调用启用静态检查，整数不能冒充引用，布尔不能用作长度、下标或字节值。未使用向量内置的程序不链接这套运行时。

| 内置调用 | 成功 | 失败 |
| --- | --- | --- |
| `新建字节向量(长度)` | 新的零初始化对象，允许零长度 | 负长度、过大或容量不足时返回空引用 |
| `向量长度(对象)` | 返回请求长度 | 空引用返回 `-1` |
| `向量读字节(对象, 下标)` | 返回 `0..255` | 空引用或越界返回 `-1` |
| `向量写字节(对象, 下标, 值)` | 返回 `0` | 空引用、越界或值不在 `0..255` 时返回 `-1` 且不写入 |

下标从零开始。当前对象区为 1 MiB，包括每块八字节头；单对象载荷最多 1,048,568 字节。块头记录请求长度、包含块头的物理跨度及标记／分配位。对象不移动，当前只含字节，没有子引用。这些上限是内部实验契约。

## 回收点与精确根

- 单线程运行时先尝试未使用的区尾，再找已有空闲块；两者都失败时暂停程序，标记、清扫、合并相邻空块并收回空闲区尾，然后重试一次。仍无可用空间时返回空引用。复用时清零本次请求的载荷。
- 只登记形参、局部变量及求值中的临时实参里确认为向量的栈槽。登记的是槽地址，因此局部重新赋值后自动读到新引用。临时实参保留至整个调用返回；被调函数结束时恢复进入前的根深度。不扫描任意整数或未初始化栈槽。当前不支持向量全局变量及嵌套块的向量声明，局部保活到函数返回，不做最后一次使用分析。
- 主任务影子根表容量 65,536 项；启用原生协作任务时，每个工作任务独立有 16,384 项。登记和退栈只作用于当前任务，回收前核对所有未结束任务的根表完整性，再扫描主任务及仍活着的工作任务，包括已挂起的栈。已结束任务的根表不再访问，含栈保护终止。如果活根表溢出，只记逻辑深度并略过回收；退栈或任务结束后恢复。GC 仍是单线程、全调度器暂停，不做移动式整理。空闲字节可能碎片化。
- 白泽 ABI：最后一个参数在 `[rsp+8]`，之前依次在 `[rsp+16]`、`[rsp+24]`，`rax` 返回。可读汇编在 `runtime/vector-gc-x64.S`；编译器直接发射同一组机器码，填入对象区和调度器区地址；只用向量时，调度器区地址为零，不预留工作根表。构建白泽不依赖为这段运行时单独调用汇编器。

## 验证

- `python3 -B tests/check-managed-memory.py <第三代编译器> --baseline <上一内部里程碑第三代编译器>`：非法类型、边界访问、活对象吃满时分配失败、退栈后复用、普通程序映像一致。
- `python3 -B tests/check-gc.py <第三代编译器>`：跨调用与临时实参保活，800 轮更替和零初始化。
- `python3 -B tests/check-vector-line-count.py <第三代编译器>`：一个进程反复加载真实编译器源码、带空格的中文路径、空文件与不同换行结尾。加 `--without-gc` 对照旧编译器。文件读取仍经原有固定中转缓冲，统计逻辑读动态向量。
- `python3 -B tests/check-task-gc.py <第三代编译器>`：挂起的工作任务与主任务跨回收保活、栈保护中止后根失效。
- `python3 -B tests/check-gc-encoding.py`：可选 GNU Binutils 审计，校验汇编、发射字节、入口偏移和无重定位，不作为可信根路线的依赖。

边界检查只适用于向量内置，白泽编译器不是不受信任源码的沙箱。
