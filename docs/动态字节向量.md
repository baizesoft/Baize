# 动态字节向量（实验性内部里程碑）

`字节向量` 是静态签名中独立的引用类型，可作参数、返回值，以及函数体内以 `变量` 推断的局部。`新建字节向量(长度: 整数)` 返回向量引用；`向量长度(对象: 字节向量)` 返回整数。成功时长度可为 0；负数、超限或容量不足返回空引用，取空引用长度得到 `-1`。向量调用会启用静态检查，不能把整数当引用或把布尔值当长度。

本候选只验证动态大小的对象、引用传递与容量边界。程序仅在调用相关内置时链接运行时并获得单线程、进程私有的零初始化区。八字节区头记录已用容量，后随最多 1 MiB 的对象记录；每个对象有八字节长度头及变长载荷，首个对象最大 1,048,568 字节。分配失败不得消耗容量或破坏已有对象。这个内部上限不是未来语言承诺。**尚无索引读写、回收或并发；编译器仍不是不受信任源码的沙箱。** 没有向量调用的旧程序保持原有映像。

## 当前 x86-64 叶函数

白泽内部调用约定：唯一参数在 `[rsp+8]`，`rax` 返回；只使用调用者保存寄存器。Windows PE 与 Linux ELF 使用相同指令，`区地址` 由编译器填入。无外部调用。

```asm
新建:
    mov rcx, [rsp+8]
    cmp rcx, 1048568
    ja 失败                       # 无符号比较同时拒绝负数
    movabs rdx, 区地址
    mov rax, [rdx]
    lea r8, [rax+rcx+8]           # 上一步保证长度有界
    cmp r8, 1048576
    ja 失败
    mov [rdx], r8
    lea rax, [rdx+rax+8]
    mov [rax], rcx
    ret
失败:
    xor eax, eax
    ret
长度:
    mov rax, [rsp+8]
    test rax, rax
    jz 空引用
    mov rax, [rax]
    ret
空引用:
    or rax, -1
    ret
```
