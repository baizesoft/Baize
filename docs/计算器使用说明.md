# 白泽计算器使用说明

> 本文档从 `README.md` 拆出（2026-11-21），收纳命令行整数计算器与 Windows 桌面计算器的完整功能说明。README 只保留语言现状速查与最小可运行示例。计算器是白泽语言的**演示程序**，不是语言本体。

## 命令行整数计算器

examples/计算器.bz 接收一个表达式，支持四则运算、括号、连续正负号和空白。输入错误、除零、超限和嵌套过深会给出中文提示并返回非零状态。

在 Linux x86-64 上，使用已经构建好的白泽编译器：

```bash
./白泽编译器 examples/计算器.bz ./计算器 native-linux-x64
chmod +x ./计算器
./计算器 '2 + 3 * (4 - 6)'  # -4
bash scripts/verify-calculator.sh ./白泽编译器
```

命令行可用 计算器 '(1/3)*3' --expr 调用完整算式模式，输出八位缩放整数 100000000，表示 1。同一算式使用 --expr-text 时直接输出十进制文本 1。文本模式通常按八位小数舍入，非零值舍入后会变成零时输出第九位。两种算式模式在检测到标准输出写入失败时返回退出码 1。该模式支持乘方、函数（例如 inv(4) 求倒数、floor(-1.2) 向下取整为 -2）、科学计数法、百分比和省略乘号，内部保留九位。ans 和 m1 至 m4 需要桌面会话。默认模式接受整数，除法向零截断。字面量和中间结果须在 -2147483647 到 2147483647 之间，表达式最多 1024 字节。第二个参数 --4 或 --8 启用四位或八位定点小数，返回分别放大 10000 或 100000000 倍的整数。

## Windows 桌面计算器

Windows 桌面原型使用 WinForms 处理窗口、鼠标及键盘事件。白泽实现表达式解析与运算，由现有构建脚本生成 Windows 运算程序。构建运算程序使用第三代白泽编译器，直接生成 Windows PE。

```powershell
powershell -NoProfile -STA -File scripts/start-calculator.ps1
powershell -NoProfile -STA -File scripts/start-calculator.ps1 -Verify
```

从源码启动时会按需构建第一代白泽编译器，并用它编译计算器。计算器源码、编译器源码、PE 种子或构建脚本更新后会重新构建。

桌面版使用标准按键模式。白泽解释按键顺序、处理逐步运算、重复等号、百分号、正负号、平方、平方根、倒数、清除当前输入、退格和错误恢复。记忆操作支持 MC、MR、M+、M− 和 MS，分别可用 Ctrl+L、Ctrl+R、Ctrl+P、Ctrl+Q 和 Ctrl+M 操作。窗口底部下拉列表可预览并切换 M1 至 M4，记忆键只作用于当前寄存器，并在窗口关闭时结束，桌面宿主传递按键并格式化结果。实测 2 + 3 × 4 = 20、2 + 3 = = 8、200 + 10% = 220。百分比用作乘数或除数时保留原数值和百分号次数，避免过早截断。例如 1,000,000,000 × 0.00000001% = 0.1。例如 0.00000001 ÷ 0.00000001% = 100。从历史复制或编辑这类算式时，乘数或除数末尾的百分号仍按同一精度处理。输入算式时，若加减号右侧的一项以百分号结束，该比例以当前左值为基数。例如 200+10%-10% 得到 198。首项或独立括号里的百分比按比例值计算，例如 10%+3 得到 3.1，200+(10%) 得到 200.1。退格只编辑正在输入的数字，保留百分比、平方根等计算得到的操作数。要清除该操作数，可用 CE。桌面版接受键盘输入八位小数。结果通常显示八位小数，非零值若舍入到八位会变成零，则显示第九位。继续输入第九位时保留原值并提示，可退格后继续编辑。输入会超过计算范围时，标准模式拒绝该数字，保留当前操作数和待完成的运算。编辑时保留小数点、末尾的零及负零符号，结算后显示数值。运算内部保留九位，多余内部位向零截断，显示时对半数向远离零的方向舍入。例如 1 ÷ 3 显示 0.33333333，再乘 3 显示 1。历史复用保留内部值。命令行 --4 与 --8 模式继续按对应位数向零截断。桌面宿主运行一个持续的白泽进程，用标准输入逐字节传递按键。每个命令返回六行整数，依次为状态码（8 表示输入超范围，9 表示小数超过八位，两种状态都保留原值）、八位缩放显示值、历史运算码、历史左值、历史右值、九位缩放内部值。F 启用编辑显示，H 同时启用编辑显示和九位历史操作数。J 与 H 相同，但第九行提供九位缩放的累计值。桌面窗口先发送 J，三条命令都无响应。启用后普通响应追加第七行：-1 表示按数值显示，0–8 表示编辑中的小数位数（0 保留小数点），-2 至 -10 表示带负号的零及其小数位数，-11 表示不带小数点的负零。第八行是待完成的运算码（0 表示没有待完成运算），第九行是累计值（F 和 H 使用八位缩放，J 使用九位缩放）。窗口根据这些状态显示当前算式，结算时显示实际使用的操作数。普通命令是单字节按键，小写 j、k、l、m 分别选择 M1 至 M4。大写 W 单独返回四行记忆值，J 模式使用九位缩放，其他模式使用八位缩放。读取时保留当前运算。历史复用命令以 I 开头，后接有符号的内部值和换行。粘贴数值命令以 P 开头，算式求值命令以 T 开头，分别后接十进制数或算式和换行。预览命令 U 与 T 使用相同格式，只返回求值结果，不更改按键状态。启用 F、H 或 J 后，T 和 U 响应还有第十行，提供规范化算式的 UTF-8 游标位置，用于定位语法错误。运算码为 0 时无需新增历史。启用 H 或 J 且运算码非零时，响应末尾追加九位缩放的左右操作数。复制或编辑历史算式时使用这些值，避免重算丢失保护位。白泽主动刷新后继续等待下一个按键。检测到响应写入或刷新失败时，会话以退出码 1 结束。桌面端等待一条完整响应最多两秒，超时后停止运算进程，下一次输入时重新创建。关闭窗口时关闭输入管道并停止运算进程。

标准窗口可用「置顶」或 Ctrl+T 切换置顶状态。「紧凑」或 Ctrl+Shift+T 切换只显示常用按键的小窗口。两种视图使用同一计算状态，置顶可独立切换。窗口可以展开最近 50 条成功运算。用鼠标双击、回车或点击「使用结果」可将选中结果放回本次计算。点击「复制算式」会复制完整的算式文本，四则算式、平方和平方根可通过 Ctrl+Shift+V 重新求值。也可点击「编辑算式」带入编辑窗口，修改后成功求值会生成新记录。标准模式以逗号分隔整数的千位，按钮和 Ctrl+C 可复制当前显示的数值。Ctrl+Shift+C 可复制无千位分隔符的完整内部数值，最多九位小数，再用 Ctrl+V 粘贴回来继续计算。小键盘的小数键统一输入点号，键盘也接受 ×、÷、− 和 ±。可用 @、√ 或 Q 开平方，用 ² 或 S 求平方，用 R 求倒数。Ctrl+V 可粘贴一个带符号的十进制数，最多九位小数，接受标准千位逗号分组，例如 -1,234.50，也接受科学计数法，例如 1.25E+3。九位小数粘贴后保留完整值供运算，输入新数字会替换该值。科学计数法展开后须能精确表示为最多九位小数，粘贴时保留待完成的运算。粘贴最多八位小数的值可继续退格或追加数字。无效或越界的粘贴会提示并保留当前运算。发生运算错误后，可以直接输入数字、小数点或粘贴有效数值来开始新的计算。Ctrl+Shift+V 可粘贴算式，规范化后最多 1024 字节，支持括号、×、÷、−、乘方 ^、平方 ²、平方根 √ 和科学计数法。支持常量 π，并可在括号、常量或函数前省略乘号，例如 2π、2(3+4) 和 2sqrt(9)，由当前白泽会话按九位内部精度求值，显示时舍入到八位，结果作为当前操作数。求值失败会保留原运算。成功的算式会写入历史，可复用九位内部结果。也可点击「输入算式」或按 Ctrl+E 打开编辑窗口。可先点「预览结果」核对数值，也可勾选「自动预览」，停止编辑约 250 毫秒后更新。预览不会更改当前运算或写入历史。算式中的 ans 引用求值前的当前数值，保留九位内部精度。重算历史算式时，ans 以重算当时的当前值为准。算式也可直接使用 m1 至 m4 引用对应的记忆寄存器，取九位内部值。求值不会切换记忆槽或修改寄存器。按回车计算并接入当前运算，出错时可在原窗口修改，语法错误会定位到对应的输入字符。标准模式的历史自动保存到 %LOCALAPPDATA%\BaizeCalculator\history.json，重开程序仍可使用，恢复结果保留九位内部定点值。磁盘暂时无法写入时，窗口保留本次结果和待保存记录，下次产生历史记录时重试。「清空历史」会同时删除磁盘记录。磁盘记录无法删除时，窗口保留记录并提示重试。记忆键的值仍只在当前窗口会话中有效。

`输入字节()` 从标准输入读取一个原始字节，返回 0–255，文件结束返回 -1，读取失败返回 -2。Linux 和 Windows 的 `输出` 直接写入标准输出，`输出刷新()` 返回 0。 `输出字节(值)` 写入一个 0–255 的原始字节，成功返回 0，参数或写入失败返回 -2。

函数调用可直接用作语句，例如 清空输入()，执行其副作用并忽略返回值。算术表达式仍用于赋值、输出、条件或返回等语句。

### 绘图

桌面窗口底部的「绘图」可画出含 x 的四则运算和幂表达式，例如 x^2 和 1/x。^ 的指数范围为 -64 到 64，可包含 x。正底数支持小数指数，例如 x^0.5 和 2^x。负底数的指数必须为整数。幂从右向左结合，且优先于一元正负号，因此 -x^2 表示 -(x^2)。可以输入横轴起止值和对称纵轴上限，纵轴上限最小为 0.000000001。已有图形时，在纵轴上限输入框按回车可直接调整显示，保留采样与标记。白泽默认在横轴区间等距采样 201 点，界面可选 401 或 801 点。绘图前会检查完整表达式的语法。语法报错时，命令行在第二行给出从 0 开始的 UTF-8 字节偏移，桌面窗口会指出对应曲线并定位输入字符。除零、超出函数定义域或溢出的采样点断开。相邻点会额外检查区间中点。中点无效时断线，即使两端同号。同号区间若中点幅值达到峰值，再检查四分之一和四分之三处，减少偏离中点的极点误连。异号端点还会比较中点和两端的数值，以减少跨极点的误连。窗口可用分号分隔最多四个表达式，例如 x; -x; sqrt(x)。每条曲线使用独立颜色和图例，共用同一坐标范围。网格和数字刻度按当前横轴区间和纵轴上限自动调整。跨出纵轴范围的曲线按原斜率裁剪到绘图区边缘。「适配纵轴」根据当前图的有效采样调整对称纵轴，保留横轴区间和已有采样。全图没有有效采样时，该按钮不可用。即使缩放到很窄的区间，曲线、光标和 CSV 也按白泽的同一套九位定点横坐标定位。鼠标移过画布时会标记最近的采样列，也可聚焦读数框后按左右方向键逐点查看，按回车对所选采样点求值，并在画布下方显示横坐标与各条曲线的纵坐标。无效采样显示为「无值」。「求点值」可在指定横坐标重新求值。焦点在点值横坐标输入框时可按回车求值，表达式和横轴范围输入框按回车绘制。求点值适用于采样点之间或当前画面之外的横坐标。求值后可从下拉列表选择一条曲线的有效纵坐标，再点「用作标准模式输入」继续计算。修改表达式、横轴范围或采样点数后会清除旧图和曲线数据，重新绘制后可求值、查找零点与交点或导出。命令行用 计算器 --graph "x^2" 0.123 可单独计算一个点。将 --graph 改为 --graph9 可取得九位缩放整数，桌面的「求点值」、回填、绘图采样、光标读数和 CSV 导出均使用该精度。--graph9 也可用于区间采样。绘图命令检测到标准输出写入失败时返回退出码 1。放大、缩小、平移或手动修改横轴与采样点数后重绘，都会保留所选交点曲线，交点可按新范围重新查找。鼠标在画布上时可用滚轮以指向的横坐标为锚点，按钮也可缩放。按住左键横向拖动画布，松开时平移横轴并重新采样，区间宽度不变。重置坐标恢复默认横轴和纵轴。「导出」可保存 CSV 或 PNG。CSV 包含当前图的全部采样点，列按图例顺序排列为 x、y1、y2 等，无效点留空。PNG 包含当前坐标网格、曲线和完整颜色图例。函数支持 floor(x)、ceil(x)、inv(x)、abs(x)、sqrt(x)、cbrt(x)（含负数的立方根）、ln(x)、log(x) 和 log10(x)（以 10 为底）、log2(x)（以 2 为底）、exp(x)、sin(x)、cos(x)、tan(x)、asin(x)、acos(x) 和 atan(x)，也可以嵌套，例如 sqrt(abs(x))。绘图三角函数使用弧度，参数限制为 -100 到 100。表达式支持常量 pi、e 和科学计数法，例如 sin(pi*x) 和 1e-3*x。输入和常量使用九位定点小数。图中在变量、函数名或左括号前可省略乘号，例如 2x、2sin(x) 和 (x+1)(x-1)。省略的乘法与显式乘除同级，从左向右计算。紧跟数字的 e/E 用于科学计数法，欧拉常量可写作 2*e。

「查找零点」在当前横轴范围内按当前图的采样点数检查每条曲线，并细化异号区间和同号的局部低谷。取整造成的异号跳跃会跳过，防止把没有经过零的台阶报为零点。每条最多显示 16 个近似零点。异号区间细化到相邻定点仍无精确零时，选择残差较小且满足容差的端点。同号局部低谷必须求值得到定点零才会被报告，采样没有识别到的相切点仍可能漏过，连续零值采样只报告起点。命令行在区间参数后加 z，例如 计算器 --graph "x^2-2" -2 2 z 801。z 后可选采样点数，省略时为 201。每行输出放大 1000000000 倍的零点横坐标。绘制多条曲线后，可以选择两条并点击「查找交点」。程序用相同的零点方法计算两式之差，显示交点的近似横纵坐标，纵坐标保留九位小数。点「复制交点」可按每行一个坐标复制结果。改选曲线会清除上一组交点标记和读数。两条曲线的当前采样值全部一致且至少有两个有效点时，提示采样点重合。当前画面内的交点会标在图上，零点也会按曲线颜色标在横轴上。

命令行可用 计算器 --graph "1/x" -10 10。可在命令末尾加 201 到 801 的采样点数，横轴区间须能在九位定点刻度上容纳所选点数。每行是一个放大 100000000 倍的纵坐标。9223372036854775807 表示该点无效。横轴须位于 -1000 到 1000。

### 科学计算

打开「科学计算」时会带入标准窗口上当前有效的显示值。「使用结果」可将成功结果按显示精度回填，切换函数时保留该输入。「用作标准模式输入」可把标准模式范围内的结果带回当前算式。下一步运算仍应用所选函数的定义域和输入范围。

窗口底部的「科学计算」支持幂运算与阶乘。命令行可用 计算器 --science --help 查看运算码和九位精度选项。打开窗口时会带入标准模式当前有效值，保留九位内部小数精度。正底数可以取小数次幂，负底数需要整数指数。指数范围为 -64 到 64，幂运算采用与桌面标准模式相同的定点范围，桌面科学模式保留九位小数。命令行 --science p9 输出九位缩放整数。0 的零次幂和负次幂会报错。例如 计算器 --science p 9 0.5 输出 300000000，表示 3。阶乘接受 0 到 20 的整数，结果精确显示。

命令行可用 计算器 --science p 2 -3，输出放大 100000000 倍的整数 12500000。计算器 --science f 20 输出整数 2432902008176640000。

科学计算也支持正弦、余弦和正切。可选度、弧度或百分度（GRAD），弧度输入范围为 -100 到 100。计算器 --science s 30 d 输出 50000000，表示 0.5。运算码 s、c、t 分别对应 sin、cos、tan，单位 d、r、g 分别表示度、弧度和百分度。桌面三角函数和反三角函数保留九位小数，命令行运算码 s、c、t、S、C、T 后加 9 可输出九位缩放整数。正切在直角附近的有效精度会下降，超出定点范围时报错。

反正弦、反余弦和反正切可按度、弧度或百分度输出。反正弦和反余弦接受 -1 到 1 的数值。计算器 --science S 0.5 d 输出 3000000000，表示 30 度。大写 S、C、T 分别对应 asin、acos、atan。

自然对数 ln 和常用对数 log₁₀ 接受正定点数。桌面保留九位小数，命令行 --science n9 和 --science l9 输出九位缩放整数。计算器 --science n 2 输出 69314718，表示约 0.69314718。计算器 --science l 0.001 输出 -300000000，表示 -3。

自然指数 eˣ 和十进制指数 10ˣ 支持小数指数。桌面保留九位小数，命令行 --science e9 和 --science b9 输出九位缩放整数。计算器 --science e 1 约为 2.71828183，计算器 --science b 0.5 约为 3.16227766，命令行均输出放大 100000000 倍的整数。接近零的结果可能舍入为 0，超出定点范围时报错。

整数次方根支持 1 到 64 次。桌面保留九位小数，命令行 --science g9 输出九位缩放整数。负数可以开奇次方，开偶次方会报错。计算器 --science g -27 3 输出 -300000000，表示 -3。

任意底数对数要求真数为正，且底数为正且不等于 1。桌面保留九位小数，命令行 --science k9 输出九位缩放整数。计算器 --science k 8 0.5 输出 -300000000，表示 -3。底数接近 1 时，有效精度可能下降，超出定点范围时会报错。

桌面科学计算的绝对值、倒数和取余保留九位小数。命令行 --science r9 计算倒数并输出九位缩放整数。命令行 --science a9 和 --science %9 输出九位缩放整数。取余 mod 使用向零截断的整数商，非零余数与被除数同号。计算器 --science % -7.5 2 输出 -150000000，表示 -1.5。计算器 --science a -1.5 取绝对值，输出 150000000。

向下取整 floor 取不大于输入的最大整数，向上取整 ceil 取不小于输入的最小整数。运算使用内部九位小数。计算器 --science F -1.000000001 得 -2，换成 U 得 -1，命令行输出对应的八位缩放整数。

科学模式的定点输入支持 e/E 科学计数法，例如 2.5e-6。换算后的数值须能用九位定点小数精确表示并落在原输入范围内。阶乘和根指数仍使用整数字面量。

科学模式、算式和绘图均支持 sinh、cosh 和 tanh。桌面保留九位小数，命令行在运算码后加 9 可输出九位缩放整数。命令行运算码分别为 H、I、J，例如 计算器 --science H -1 输出 -117520119，表示约 -1.17520119。tanh 对大输入趋近 ±1，显示值可能舍入为 ±1。

### 日期计算

窗口底部的「日期计算」可同时查看两个日期相隔的年、月、日及总天数，也可从指定日期按天、月或年向前或向后移动。目标月没有原日期对应的日时，取目标月最后一天。一次移动多个月时直接计算目标月。「加年/月/日」和「减年/月/日」将年与月合并后移动，最后加减天数。命令行可用 计算器 --date a 20240131 1 1 1，输出 20250301。窗口中输入 YYYY-MM-DD，支持公历 0001-01-01 至 9999-12-31。日期框旁的「日历」可点选系统日历支持的日期。超出日历控件范围的日期仍可直接输入。同一天相隔 0 天，颠倒两个日期的顺序时结果相同。年、月、日按能够从较早日期移动的完整月份计算，再补上剩余天数。

命令行的日期输入为八位 YYYYMMDD。计算器 --date d 20240228 20240301 输出 2。将 d 改为 c 会依次输出年、月、日和总天数，每项占一行。计算器 --date a 20240228 1 输出 20240229。运算码 s 表示减去指定数量。加减操作默认按天，末尾加 m 按月，加 y 按年。例如 计算器 --date a 20240131 1 m 输出 20240229。「加周数」和「减周数」按每周七天移动日期，例如 计算器 --date a 20241230 2 w 输出 20250113。加减月数或年数时可勾选「起始日为月末时，结果也取月末」。例如从 2024-01-31 连续加两次一个月，依次得到 2024-02-29 和 2024-03-31。命令行将月数单位 m 改为 e，或将年数单位 y 改为大写 E，即可使用该规则。命令行以整数输出结果日期，年份的前导零由桌面窗口补齐。

「星期与周数」可查看公历日期对应的星期和 ISO 周数。ISO 周以星期一开始，年初和年末的日期可能归入相邻年份的周。例如 2021-01-01 是星期五，属于 2020 年第 53 周。命令行 计算器 --date w 20210101 依次输出 ISO 周年、周数和星期编号，星期一为 1。也可在「按 ISO 周查日期」中反查公历日期，例如 计算器 --date W 2020 53 5 输出 20210101。没有第 53 周的年份会拒绝输入第 53 周。「星期与周数」算出结果后可点击「按周反查」带入周年、周数和星期。在反查界面点击「用作起始」可把日期带回。

「相隔工作日」统计较早日期之后、到较晚日期为止的周一至周五。两端相同则为 0。例如 2024-03-01 到 2024-03-04 相隔 1 个工作日。默认按星期计算。也可在三种工作日运算中输入最多 32 个例外日期，例如 -2024-03-04 表示休息，+2024-03-02 表示上班，多项以逗号分隔。命令行在工作日运算末尾追加不带日期横线的列表，例如 +20240302,-20240304。例外日期由用户填写。成功计算后，当前应用会话会记住这组例外，重开日期窗口可继续使用。清空列表并成功计算可清除它。命令行可用 计算器 --date b 20240301 20240304。「加工作日」和「减工作日」跳过周六和周日，从起始日期的次日或前一日开始计数。数量为零时返回原日期。得到新日期后可点击「用作起始」，沿用现有运算和数量继续推算。计算器 --date a 20240301 1 b 输出 20240304。

### 单位换算

窗口底部的「单位换算」支持毫米、厘米、米、千米、英寸、英尺、码和英里，华氏度、开尔文和摄氏度，毫克、克、千克、磅、盎司和市斤，以及米/秒、千米/小时、英里/小时和节。输入使用小数点，支持正负数和最多九位小数，输入绝对值上限为十亿。也可输入 e/E 科学计数法，例如 1e6，展开后的数值须能用九位定点小数表示。白泽用整数比例和温度偏移换算，结果通常舍入到八位小数，中点向远离零的方向舍入。桌面换算和命令行 --convert-text 在八位结果为零时尝试显示第九位；--convert 继续输出八位缩放整数。超出定点结果范围时显示错误。

时间支持毫秒、秒、分钟、小时、天、周和固定 365 天的年。数据容量支持 bit、B、kB、MB、GB、TB、KiB、MiB、GiB 和 TiB。1 kB 是 1000 字节，1 KiB 是 1024 字节。「交换单位」会对调来源和目标并保留输入值。「反向换算」会用本次显示结果作为新输入，对调单位后立即计算。结果超出输入范围或油耗舍入为零时，该按钮不可用。

面积支持平方厘米、平方米、公顷、平方千米、市亩、平方英寸、平方英尺、平方码和英亩。体积支持毫升、升、立方米、美制加仑、英制加仑、美制杯、美制液量盎司和英制液量盎司。

压力支持帕、千帕、兆帕、巴、标准大气压、PSI 和托。能量支持焦、千焦、兆焦、瓦时、千瓦时、热化学卡和热化学千卡。1 标准大气压等于 760 托，1 千瓦时等于 3.6 兆焦。

功率支持瓦、千瓦、兆瓦、机械马力和公制马力，机械马力的换算系数舍入到皮瓦。频率支持赫兹、千赫、兆赫、吉赫和转/分钟。按每转计一个周期，1500 转/分钟等于 25 赫兹。

角度支持度、弧度、百分度、圈、角分和角秒。1 圈等于 360 度或 400 百分度，换算保留多圈角度。弧度换算采用圆周率近似值。修改数值或单位后，窗口会清除上一次的结果。勾选「自动更新」后，停止修改约 250 毫秒即重新换算，也可按回车立即换算。

油耗接受正数，支持升/百公里、千米/升、英里/美制加仑和英里/英制加仑。升/百公里与其余单位之间使用倒数关系。例如 8 升/百公里约等于 29.40182292 英里/美制加仑。

网络速率支持 bit/s、kbit/s、Mbit/s、Gbit/s、B/s、kB/s、MB/s、GB/s、KiB/s、MiB/s 和 GiB/s。100 Mbit/s 等于 12.5 MB/s，约为 11.92092896 MiB/s。

「全部单位」列出当前类别的换算结果，单项超出范围时会单独标记。点「复制全部」可复制整组结果。选中有效且在标准模式范围内的结果，可带回标准模式继续计算。带入失败时保留来源窗口与所选结果，便于重试。命令行将目标单位改为 all，可按单位编号顺序得到结果，每项输出状态和结果两行。--convert 输出八位缩放整数，--convert-text 输出与桌面相同的十进制文本。状态 0 表示成功，3 表示结果超出定点范围。单项和批量换算检测到标准输出写入失败时都返回退出码 1。

加速度支持 m/s²、cm/s²（Gal）、mm/s²、ft/s² 和标准重力 g₀。力支持牛顿、千牛、达因、千克力和磅力。1 g₀ 等于 9.80665 m/s²，1 磅力约等于 4.44822162 牛顿。扭矩支持牛顿米、牛顿厘米、千克力米、磅力英尺和磅力英寸。1 磅力英尺约等于 1.35581795 牛顿米，等于 12 磅力英寸。从标准模式打开单位换算时，若当前数值在换算输入范围内，会自动带入。「用作标准模式输入」可把换算结果中的数值带回标准模式，作为当前操作数继续计算。该按钮只在结果可作为标准模式输入时可用。

命令行可用 计算器 --convert --help 查看单项和批量输出格式。可用 计算器 --convert 8 4 1 将 1 英里换算成千米，输出放大 100000000 倍的整数 160934400。长度编号 1–8 对应上面的顺序，温度编号 9–11、质量编号 12–17、速度编号 18–21、时间编号 22–28、数据容量编号 29–38、面积编号 39–47、体积编号 48–55、压力编号 56–62、能量编号 63–69、功率编号 70–74、频率编号 75–79、角度编号 80–85、油耗编号 86–89、网络速率编号 90–100、加速度编号 101–105、力编号 106–110、扭矩编号 111–115，均按上面的顺序。

### 程序员模式

窗口底部的「程序员模式」支持 BYTE、WORD、DWORD 和 QWORD，分别对应无符号 8、16、32、64 位。可选二进制、八进制、十进制和十六进制输入，结果同时显示四种进制以及有符号十进制补码值。十进制操作数可以输入负数，最小值由所选字长决定。支持 AND、OR、XOR、NOT、左移、逻辑右移、算术右移、双向循环移位、加减乘法、有符号和无符号除法及取余。加减乘法按所选字长回绕，循环移位会将移出的位补到另一端。移位数用十进制输入，须小于所选字长。进制解析、位运算和范围检查由白泽实现。

切换输入进制时，左右操作数会转换为新进制并保留位值。移位运算的右侧是十进制位数，切换进制时保持原样。若操作数在原进制下无效或超出所选字长，窗口会提示并保留原进制和输入。

程序员模式的「使用结果」将本次结果按当前进制回填到左操作数，可保留右操作数和运算继续计算。修改任意操作数、字长、进制或运算后，旧结果会清除。十进制回填使用无符号表示。

「编辑左值位」按所选字长显示左操作数的各位，从最高位排到最低位。点击位可在 0 和 1 之间切换，应用后按当前进制回填左操作数。右操作数和运算选择保留。十进制回填按无符号位串显示。

白泽内置函数 整数位与(左, 右)、整数位或(左, 右)、整数位异(左, 右) 和 整数位反(值) 对 64 位二进制位操作。逻辑左移(值, 位数) 丢弃移出的高位，逻辑右移(值, 位数) 在高位补零。位数为 0–63 时执行，超出此范围返回 0，结果按有符号 64 位整数解释。程序员模式调用这些内置函数，并按选择的字长截断左移和取反结果。

命令行亦可使用 计算器 --programmer 16 x FF 0F，输出 240。缩小字长时保留原操作数，并在数值不适合新字长时提示。桌面程序员模式可用 Ctrl+1、Ctrl+2、Ctrl+3、Ctrl+4 切换十六、十、八、二进制，对应的 Ctrl+Shift+1 至 Ctrl+Shift+4 切换 BYTE、WORD、DWORD、QWORD。程序员模式可粘贴与所选进制匹配的 0x、0o、0b 前缀，以及数字之间的单个下划线，例如十六进制 0xFF_FF。在数值操作数输入框按 Ctrl+Shift+V，可按剪贴板的 0x、0o、0b 前缀识别进制，并转成当前进制。移位量仍输入十进制数字，位字段运算会显示相应输入格式。单操作数运算会将右值设为只读，并保留原文本。选择「复制当前进制」或按 Ctrl+Shift+C 可复制适合放回代码的结果，二进制、八进制和十六进制会附带前缀。可将 SIGNED 行的有符号值或 DEC 行的无符号值带回标准模式继续计算。两个按钮分别判断结果是否在标准模式范围内。例如 BYTE 的 FF 可分别以 -1 或 255 带回。「从标准模式取整数」（按标准模式内部值判断整数）将当前显示的整数按所选进制带入左操作数，保留右操作数，并按所选字长的有符号范围校验。运算码 v、a、o、x、n、l、r 分别对应转换、AND、OR、XOR、NOT、左移和逻辑右移。h 表示在高位复制符号位的算术右移。大写 L 和 R 分别表示循环左移和循环右移，+、-、m、d、% 分别表示加法、减法、乘法、无符号除法和无符号取余。大写 D 和 M 分别表示有符号除法和取余。商向零截断，非零余数与被除数同号。有符号商超出所选字长时会报错，例如 BYTE 模式的 -128 ÷ -1。除数为零时报错。转换、NOT 和字节序反转的右操作数可传空字符串。字节序反转的运算码为 b，按所选字长反转字节顺序，例如 DWORD 的 0x12345678 变为 0x78563412。大写 B 按字长逐位反转，例如 BYTE 的 0x12 变为 0x48，右操作数可留空。运算码 q 计算两个操作数不同的位数。运算码 f 提取位字段，右值用十进制起点:长度，从最低位 0 开始，例如用 4:8 从 0xABCD 提取 0xBC。大写 F 按补码提取有符号位字段并扩展到所选字长，同一个字段的有符号值为 -68。运算码 i 写入位字段，右值格式为十进制起点:长度=十六进制值。例如对 0xABCD 使用 4:8=0x42，结果为 0xA42D。字段之外的位保留。运算码 p、c、t 分别计算置位数、前导零和尾随零，右操作数可传空字符串。对零计算前导零或尾随零时，结果等于所选字长。末尾可加字长，默认 32。命令行用有符号整数传输 64 位位串，例如十进制最大 QWORD 18446744073709551615 在命令行返回 -1，窗口显示完整的无符号值。

### Windows 便携包

从仓库根目录运行 powershell -NoProfile -File scripts/package-calculator.ps1，可生成 dist/BaizeCalculator-win-x64.zip。打包脚本验证三代原生 PE 编译器后，由第三代直接生成运算程序，并在独立解压目录中执行桌面验收。可用 -OutputPath 指定输出位置。CI 连续打包两次并比较 ZIP 的 SHA-256。

在 Windows x64 解压全部文件，双击 Start-Calculator.cmd。客户端使用系统自带的 Windows PowerShell 和 WinForms，运算程序随包分发。
