# 白泽官方日志（基础版）

日志库用白泽编写，随工具链提供。它与用户程序一起编译成原生可执行文件，不需要 Python 才能运行。当前编译器还没有模块导入，官方宿主启动器用 `--日志` 选择性地把库与源码合成后交给编译器；Python 只负责宿主命令和验收。

## 编译与实用示例

```text
python3 -B scripts/baize.py build --compiler <本机白泽编译器> --日志 --合入 examples/源码行统计核心.bz examples/源码行统计.bz -o <目标文件>
<目标文件> <源码文件>
<目标文件> <源码文件> --log-json
<目标文件> <源码文件> --log-text
```

行数总是单独输出到 stdout。默认没有日志；使用任一日志参数时，stderr 另写一行，消息是此次明确传入的文件路径，数值是行数。开启时请确认可以把路径写进日志。参数错误退出 2；统计已输出、但所请求的日志写入失败时退出 3。构建器不会覆盖已有目标文件。

## 库的调用契约

- `日志设级别(级别) -> 整数`：`0 / 1 / 2 / 3` 分别是 `DEBUG / INFO / WARN / ERROR`。默认最小级别为 `INFO`。
- 将消息放入 `日志消息区`（1024 字节），例如用已有的 `参数读取` 或 `文件读取` 填充。调用 `日志记录(级别, 格式, 消息字节数, 数值)`；格式 `0` 为文本，`1` 为一行 JSON。调用者提供实际字节数，不依赖 NUL 终结；库不替调用者截断。第一版没有任意键值字段：JSON 固定为 `level`、`message`、`value`，其中 `value` 是一个有符号整数。
- 写入或被级别过滤返回 `0`；参数越界、未过滤的消息不是合法 UTF-8 返回 `-1` 且不输出；可检测的流错误返回 `-2`。流错误可以发生在记录中途，不承诺撤销已经写入的字节。引号、反斜杠和 U+0000–001F 在 JSON 中转义；文本不转义双引号，其余控制字符按同一规则处理。
- 基础版的缓冲、最低级别与写入状态是进程内的共享全局数据，限单线程使用。按字节同步写入，无异步队列、日志滚动、并发原子性、自动脱敏或时间戳；不把该版当作高吞吐线上日志方案。

`python3 -B tests/check-log-library.py <第三代编译器>` 会运行实际原生程序，核对两路输出、级别、UTF-8 边界和源码工具的两个日志选项。
