# 基础静态类型（第一版）

```text
函数 计数(数: 整数) -> 整数:
    变量 结果 = 数 + 1
    返回 结果
```

- 文件中出现显式签名或 `变量 名 = 表达式` 时，启用静态检查。启用后，同一文件每个函数都要标注所有形参与返回类型。旧的无标注文件仍走原有语义；本阶段不把编译器源码和可信种子迁移到新语法。
- 支持 `整数`（有符号 64 位）和 `布尔` 的形参、返回值和变量。`变量` 仅用于函数最外层局部声明，从初始化式推断整数或布尔，之后不能改类型。现有显式声明也检查初始化和赋值。
- `如果`、`当` 的条件必须是布尔；有序比较使用整数，布尔只支持同类型相等和不等。算术和一元负号要求整数。参数数量、参数类型和返回类型都在发射前检查；有标注的函数不能依靠默认返回值。循环不算作必定返回。
- 固定字节数组限全局：下标须为整数，读取得到零扩展的整数，直接写入只接受不截断的 0–255 整数字面量。数组边界检查不在本阶段；通用动态字符串、结构体和泛型尚未实现。
- 静态路径覆盖 `参数数量`、`参数读取`、`文件读取`、`文件写入` 和 `输出`；不认识的内置不会假定返回整数。文件路径可取字面量或现有字节缓冲区，缓冲区长度和路径终止符仍由调用者遵守。局部不允许遮蔽全局，同名声明不允许重复，嵌套块内先不新增局部声明。这些是保留现有后端及自举的第一版限制。
- 失败在创建目标文件前报告中文诊断。运行时仍复用原有 PE/ELF 后端和 ABI，没有把整数或布尔改成动态值。
- 验收：`python3 -B tests/check-static-types.py <第三代编译器>`；真实应用是迁移后的 `examples/源码行统计.bz`，由 `tests/check-layout.py` 同时验证中文和带空格路径、真实编译器源码、空文件和缺文件。Python 只运行验收，不参与编译。
