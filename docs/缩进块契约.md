# 缩进块最小契约（研发候选）

- 布局块由行尾半角冒号引入，适用于 `函数`、`如果`、`否则`、`当`。条件可省略外层括号。
- 只用空格作布局缩进；每层恰好四个空格。同层对齐，退回已经打开的层级；块必须有至少一条语句。Tab、非四格层进、缺块和不匹配回退以中文诊断报告物理行号，不写目标文件。
- 空行和仅含 `#` 注释的行不改变缩进；块头末尾可有 `#` 注释。配对圆括号或方括号中允许跨行表达式，不参与布局。支持 LF、CRLF，以及无末尾换行。
- 花括号原有源码继续可编译。布局块和花括号块可以分别出现在同一文件的顶层，但第一版不在一种块内部嵌套另一种块写法。
- 编译器在现有词法结果上归一化布局边界，复用现有 AST 和原生后端。当前可信种子不认识布局语法，编译器源码仍用花括号；用户程序可以用缩进。
- 布局诊断第一版报告物理行号，不提供列号。布局层深最多 255，受编译器现有记号容量限制。
- 用 `python3 -B tests/check-layout.py <第三代编译器路径>` 在 Windows / Linux 验证两种写法、错误位置及实际源码行统计程序。`examples/源码行统计.bz` 接收一个文件路径，支持 LF、CRLF 和无末尾换行，不读取超出当前缓冲区上限的文件。
- 完整验收还包含两平台三代自举和 GNU 独立对照。ABI、类型和后端不在本阶段扩展。
