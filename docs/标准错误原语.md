# 标准错误字节写入（运行时内部接口）

`错误输出字节(值)` 把 0–255 的一个整数作为原始字节写入进程标准错误。成功返回 `0`；参数越界或可检测的写入失败返回 `-2`。不作字符转换，不附加换行，不写标准输出。Linux 遇 `EINTR` 重试；系统信号仍由当前运行时和宿主管理，例如关闭的管道可能触发默认的 SIGPIPE。Windows 使用标准错误句柄和 `WriteFile`。

此接口只为后续的日志与测试报告提供运行时基础，不是日志标准库。静态模式要求恰好一个整数实参。后端只在实际调用内置原语时链接它；不使用原语的程序不改变原有映像布局，保留现有种子的三代比对。

使用 `python3 -B tests/check-stderr.py <第三代编译器>` 验证 stdout/stderr 分离、不可写句柄、字节上下界、静态签名调用和不使用原语的对照。加 `--baseline <阶段 2 编译器>` 可额外比较普通程序的输出映像字节。
