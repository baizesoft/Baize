# Linux x86-64 汇编种子

seed.s 是手写的白泽子集编译器，读取白泽源码并直接生成静态 ELF。使用 GNU as 和 ld 构建种子。种子启动后只使用 Linux 系统调用。

## 验收

- 运行 bash scripts/verify-stage0-seed.sh 验证种子本身。它编译扫描样例.bz 并运行产物，覆盖输入变化、二进制文件内容、UTF-8 参数、未知函数、参数数量不符、非法源码和容量边界。
- 运行 bash scripts/check-stage0-cold-start.sh 验证完整冷启动。构建种子后，脚本在独立 PATH 中移除 Rust、C 工具链和汇编器、链接器。种子在空 PATH 下直接编译 compiler/编译器.bz，得到首个白泽 ELF 编译器。该 ELF 再连续产生三代白泽编译器，比较全部字节并以最后一代运行原生正负样例。
- GitHub Actions 单独运行上述汇编冷启动验收，归档构建工具版本、种子及首个白泽编译器、三代 ELF、哈希和日志。保留原有 Rust/C 启动流程作为基线，两条路径的固定点 ELF 在本次实测中相同。

此前计划用更小的白泽过渡编译器缩小种子范围。扫描样例确定了所需的基本能力，加入函数、局部变量、除法和字符串输出后，种子能直接处理当前完整编译器源码，因此实际冷启动链无需单独的过渡源码。

## 白泽 ELF 打包器

从已有白泽编译器出发，运行 bash scripts/check-stage0-no-ld.sh 已有白泽编译器。该流程用 GNU as 产生目标文件，再由白泽打包器生成种子，后续三代原生自举在移除 ld 的环境中验收。契约见 bootstrap/stage0/ELF打包契约.md。

## 白泽汇编器

从已有白泽编译器出发，运行 bash scripts/check-stage0-no-binutils.sh 已有白泽编译器。该流程用白泽汇编器读取原始 seed.s，再用白泽 ELF 打包器构建种子。支持的指令和语法见 bootstrap/stage0/汇编器子集.md。

## 独立可信根冷启动

运行 bash scripts/check-stage0-trust-root.sh，从仓库内固定的可信种子启动，重建种子并复验三代原生自举。该流程从第一步起无需 GNU as、ld、Rust 或 C 编译器。来源、校验和更新方式见 bootstrap/stage0/可信根.md。

## 当前子集

- UTF-8 源码中的中文标识符和关键字、ASCII 标点、注释及十进制字面量。
- 全局整数和定长全局字节数组、函数块内的局部整数、赋值、字节索引读写。
- 整数加减乘除、比较、一元负号和括号，条件、循环、函数、向前引用、递归与返回。
- 参数数量、参数读取、二进制文件读写、整数输出和 ASCII 双引号文本输出。
- 源码最大 262144 字节，全局声明上限 512 个，全局数据最多 16 MiB。每个函数有最多 64 个同时存活的参数及局部整数槽位。调用数、表达式深度和块嵌套均有上限。数组索引及文件缓冲区容量由调用程序负责。
- 调用格式为 编译器 源文件 输出文件 native-linux-x64。源码错误返回非零，带 UTF-8 字节偏移，解析失败时不创建输出文件。

该子集服务于自举。局部字节数组、语言完整诊断以及其他架构仍由后续研发覆盖。
