# Linux x86-64 汇编种子

Stage 0 的目标是由手写汇编实现一个可审计的白泽子集编译器。它读取源码并直接生成静态 ELF。第一份可执行契约是扫描样例.bz，它从文件读取字节，扫描十进制前缀并将结果写回文件。通过改变输入、比较标准输出和磁盘字节、测试缺失输入和非法源码，验证编译结果由实际输入驱动。

## 样例需要的能力

- UTF-8 中文关键字和标识符、换行、注释、十进制整数、括号和花括号。
- 全局整数、全局定长字节数组、局部整数和字节索引读取。
- 赋值、加法、整数比较、条件、循环、参数传递、函数调用和返回。
- 参数数量、参数读取、文件读取、文件写入与整数输出。
- 输入输出接口与现有原生目标一致。调用格式为 编译器 源文件 输出文件 native-linux-x64。失败返回非零状态，新建输出路径不应留下 ELF。

上述范围由扫描样例覆盖起点，过渡编译器的完整范围由其实际源码补齐。过渡编译器需要从源码解析、生成并写出下一阶段编译器。冷启动验收将关掉 Rust/C 工具链，用汇编种子和过渡编译器构建现有白泽编译器，然后复跑三代原生一致性。汇编种子自身的构建命令、汇编器和链接器版本以及产物哈希应随验收记录保留。

有可执行的 Linux 宿主白泽编译器时，运行 bash scripts/verify-stage0-boundary.sh /path/to/compiler 核对契约。汇编种子实现后，同一个脚本可以直接验证它。
